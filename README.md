# Bright Pulsar Search Project

This repository contains Python code, diagnostic plots, and a short report for a pulsar search / analysis project.

## Contents

- `A.Akinc_PulsarSearch_1.5.ipynb` — main analysis script
- `PS-figures/` — generated diagnostic plots
- `A.Akinc 1-Week Pulsar Detection Report.pdf` — project report

## Methods

The data analysis includes frequency-channel normalization, 2D RFI masking, incoherent dedispersion over a DM range, DM-time diagnostics, FFT-based periodicity searches, harmonic stacking, fundamental frequency candidate searches, and folding to create a pulse profile.

## Notes

Large raw data files are not included in this repository.
